How to Subscribe (live, auto-updating)

Google Calendar (desktop browser only)

  1. Copy the Subscribe URL above
  2. Open calendar.google.com
  3. Left sidebar → Other calendars → +
  4. Select From URL
  5. Paste the URL → Add Calendar

Apple Calendar (Mac)

  1. Copy the Subscribe URL above
  2. Open Calendar app
  3. File → New Calendar Subscription
  4. Paste the URL → Subscribe
  5. Set refresh to Every 30 minutes

iPhone / iPad

  1. Copy the Subscribe URL above
  2. Settings → Calendar → Accounts
  3. Add Account → Other
  4. Add Subscribed Calendar
  5. Paste the URL → Next → Save

Outlook Desktop

  1. Copy the Subscribe URL above
  2. Open Outlook Calendar
  3. Add Calendar → From Internet
  4. Paste the URL → OK

Outlook.com

  1. Copy the Subscribe URL above
  2. Open outlook.com Calendar
  3. Add calendar → Subscribe from web
  4. Paste the URL → Import

Thunderbird

  1. Copy the Subscribe URL above
  2. Calendar → New Calendar
  3. Select On the Network
  4. Format: iCalendar, paste the URL
  5. Set a name and click Next
